# 千早爱音的日记插件

每天凌晨自动从 LivingMemory 读取记忆，生成一篇 Markdown 格式的日记。

## 指令列表

| 指令 | 用途 | 群聊可用 |
|------|------|----------|
| `/日记状态` | 查看插件运行状态、已写日记天数、最后活跃时间等 | ✅ |
| `/查看日记 [日期]` | 查看指定日期的日记，日期格式 `2026-05-05`，不填默认今天 | ❌ |
| `/测试日记` | 生成今天的测试日记（不保存到正式文件） | ❌ |
| `/补写日记 [日期]` | 补写某一天的日记，格式 `2026-05-03` | ❌ |
| `/重写日记 [日期]` | 重新生成某一天的日记 | ❌ |

## 说明

- 只有「日记状态」可以在群里用，因为只显示统计信息，不暴露内容
- 其他命令涉及日记正文内容，仅限私聊使用
- 日记文件保存在 `plugin_data/diary_writer/diaries/` 目录下

## 配置项

插件配置（AstrBot 面板 → 插件设置 → 日记作家）：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `owner_ids` | list | `["REDACTED_USER_ID"]` | 允许使用插件的用户ID列表 |
| `allow_group_commands` | list | `["日记状态"]` | 群聊中允许使用的命令 |
| `auto_write_enabled` | bool | `true` | 是否开启凌晨自动写日记 |

## 自动写日记逻辑

- 凌晨 00:00~04:00 之间运行
- 检测用户（虾仁）最后发言时间，静默 90 分钟以上才触发
- 写的是前一天的日记（比如凌晨 1 点写的是 5 月 4 日的）
- 如果当天没写完，4 点会兜底检查一次

## 私密提醒机制

在群聊里触发私密命令时，会自动生成一句提醒让用户去私聊查看。
